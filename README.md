## 🌟 The 4 Key Internship Deliverables

### 1. 🧮 Task 1 — Basic Calculator
> **Live Demo:** [Open Calculator](https://vanshika-singh-991.github.io/vanshika-internship-portfolio/task1-calculator/) &bull; **Source:** [`/task1-calculator`](./task1-calculator/)

* **Objective (Synopsis §4.1):** Provide a clean, robust, and accessible interface for arithmetic computation (`+`, `−`, `×`, `÷`, floating-point decimal calculation).
* **Core Technical Highlights:**
  * **Precision Display:** Real-time formula display tracking operand chaining and dynamic results.
  * **Division Guarding:** Gracefully handles division-by-zero (`/ 0`) by flagging errors without crashing the runtime.
  * **Keyboard Support:** Full event listener bindings (`keydown`) enabling users to compute with physical number pads and standard keys (`Enter`, `Backspace`, `Escape`).
  * **W3C Semantic Structure:** Styled with accessible tactile button states and high-contrast numerical readouts.

---

### 2. 👟 Task 2 — eCommerce Website (.sneakers)
> **Live Demo:** [Open Storefront](https://vanshika-singh-991.github.io/vanshika-internship-portfolio/task2-ecommerce/) &bull; **Source:** [`/task2-ecommerce`](./task2-ecommerce/)

* **Objective (Synopsis §4.2):** Design a static, modern product-based eCommerce storefront featuring structured catalog navigation, interactive product showcases, and shopping cart state management.
* **Core Technical Highlights:**
  * **Cupertino Bento Showcase:** Bento grid hero presenting the Nike Air Jordan, Blazer, and Crater lineups with dynamic color palettes and SVG artwork customization.
  * **Indian Rupee Currency:** Fully configured to Indian Rupee (`₹109.00`, `₹119.00`, `₹180.00`) across catalog cards, item modals, and final totals.
  * **Dynamic Shopping Bag:** Slide-out drawer state machine supporting item additions, live badge counter increments, item removals, and real-time total recalculation.
  * **Search & Filter:** Instant client-side text filtering and category pill toggles.

---

### 3. ✅ Task 3 — Dynamic To-Do List Manager
> **Live Demo:** [Open Task Manager](https://vanshika-singh-991.github.io/vanshika-internship-portfolio/task3-todolist/) &bull; **Source:** [`/task3-todolist`](./task3-todolist/)

* **Objective (Synopsis §4.3):** Build a task productivity interface combining DOM manipulation, input validation, and user feedback mechanisms.
* **Core Technical Highlights:**
  * **CRUD Operations:** Instant task creation, item completion strike-through toggling, and task deletion with immediate UI updates.
  * **Zero Data Loss:** Synchronizes all task state changes to the browser's `localStorage` so tasks persist across browser restarts and page refreshes.
  * **Input Validation:** Rejects empty submissions, provides visual focus rings, and trims whitespace.
  * **Filter Views:** Filter between `All`, `Active`, and `Completed` items with live counter statistics.

---

### 4. 🔴 Task 4 — Connect 4 Multiplayer Game
> **Live Demo:** [Open Connect 4](https://vanshika-singh-991.github.io/vanshika-internship-portfolio/task4-connect4/) &bull; **Source:** [`/task4-connect4`](./task4-connect4/)

* **Objective (Synopsis §4.4):** Implement an interactive two-player strategy game based on a 7×6 grid with gravity simulations and algorithmic winning-condition checks.
* **Core Technical Highlights:**
  * **Board State Matrix:** 2D array representation tracking disc locations for Player 1 (Yellow) and Player 2 (Red).
  * **Gravity Simulation:** Discs fall to the lowest unoccupied slot within any chosen column upon click.
  * **4-in-a-Row Algorithm:** Algorithmic referee evaluates victory conditions across all 4 vector directions simultaneously:
    1. **Horizontal** ($\leftrightarrow$)
    2. **Vertical** ($\updownarrow$)
    3. **Diagonal Positive Slope** ($\nearrow$)
    4. **Diagonal Negative Slope** ($\searrow$)
  * **Instant Match Reset:** One-click board wipe and turn reset without requiring a browser page reload.
